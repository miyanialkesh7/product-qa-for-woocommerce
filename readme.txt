Product Q&A for WooCommerce with moderated questions, answers, and email notifications.

== Description ==

Product QA for WooCommerce is a feature-rich plugin that lets customers ask questions on product pages and gives store owners a clean way to manage, approve, and respond to those queries. It is designed for WooCommerce stores that want to improve customer trust, reduce support friction, and provide helpful product information before purchase.

The plugin includes front-end question submission, answer handling, category-based feature control, and email notifications to customers who previously purchased the product. It is easy to configure for beginners and flexible enough for developers who want to extend the workflow.

== Compatibility ==

Tested with WordPress 7.1.2, WooCommerce 11.1 and Elementor 4.2. The plugin declares compatibility with WooCommerce High-Performance Order Storage (HPOS) and the Cart and Checkout blocks.

== Installation ==

1. Upload this plugin folder(including all files) to the `/wp-content/plugins/` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Go To   Woocommerce -> Settings -> Products -> Product QA
4. For more details check Screenshots.
5. Thanks.
