## Description ##

Product QA for WooCommerce adds a customer-friendly question-and-answer experience to product pages. Customers can ask questions, store owners can moderate and answer them, and buyers can receive email notifications related to the products they purchased. The plugin is designed to improve trust, reduce support questions, and keep product information easy to find.

## Compatibility ##

Tested with WordPress 7.1.2, WooCommerce 11.1 and Elementor 4.2. The plugin declares compatibility with WooCommerce High-Performance Order Storage (HPOS) and the Cart and Checkout blocks.


## Installation ##

1. Download Plugin code from this repo.

2. Unzip it and upload it to the plugins folder of your WordPress installation (wp-content/plugins/ directory of your WordPress installation).

4. Activate it through the 'Plugins' section.

5. Now Here we go. Installation is Complete.
